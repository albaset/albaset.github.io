How do I get a token?
  1. Go to github.com/settings/personal-access-tokens/new (GitHub → Settings → Developer settings → Fine-grained tokens).
  2. Under "Repository access", choose "Only select repositories" and pick this portfolio repo.
  3. Under "Permissions" → "Repository permissions", set Contents to Read and write. Leave everything else as-is.
  4. Generate the token and paste it above. It's only stored in your browser and used to talk directly to GitHub.
  5. You can revoke it any time from that same GitHub settings page.
